# Report Generation

The supplied `transportation_waybill_template.docx` is the visual master template.

- Word output is generated by populating the supplied template rather than rebuilding the layout.
- The supplied report logo replaces the template logo while retaining the template's existing image position/size.
- CR #, VAT # and footer address are taken from `ReportProfileService`.
- The Terms & Conditions wording and layout are retained from the supplied template; only the Waybill Number in the introductory paragraph is dynamic.
- The approved page-1 template contains exactly three item rows. Reports with more than three items are rejected until a continuation-page design is approved.
- PDF output is generated from the populated DOCX using docx4j's XSL-FO exporter, keeping Word and PDF based on the same source document.
- Saved Waybills row actions use compact icons with tooltips.
