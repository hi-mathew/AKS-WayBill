# W.A.S.P 1.4.0 – v9 Changes

- PDF Draft watermark direction changed to match the preferred Word watermark: bottom-left to top-right (bottom-to-top visual direction).
- Audit Log now supports a persistent `entity_label` for Waybills and displays the actual Waybill Number instead of `WAYBILL #<database id>`.
- Existing Waybill audit entries resolve their current Waybill Number through the Waybill table where available.
- Waybill CREATE/UPDATE/FINALIZE/FINAL_TO_DRAFT/DELETE audit entries now retain the Waybill Number as the entity label, including deletion entries where the Waybill row no longer exists.
- Sign out callback flow fixed: DashboardView now returns directly to LoginView instead of calling Main.handleLogout(), which previously invoked requestLogout() a second time and repeated the confirmation/backup sequence.
- Closing the application from the Login screen now exits immediately without logout/exit confirmation or backup reminder, because there is no authenticated user session and no unsaved application form.
